# 全书 C 示例规范与高风险审稿清单

## 一、C 示例统一规范

### 1. 语言、编译与范围

- 示例统一使用 ISO C99，避免编译器扩展；单文件示例应能用 `cc -std=c99 -Wall -Wextra -Wpedantic -O2 example.c -lm -o example` 编译。
- 若示例调用外部模块，明确指出依赖、输入输出接口、调用频率和可独立验证的替代桩函数；不声称不完整片段可直接编译。
- 示例围绕通用飞行器运动学、姿态/轨迹跟踪与仿真教学，不包含现实武器参数、目标选择或作战效能优化。
- 代码注释解释“为什么这样做”和边界行为，不逐字复述语法。关键语句块均有中文注释；变量名采用单位后缀或在结构体注释中给出量纲。

### 2. 单位与坐标约定

- 内部三角函数、控制计算统一用弧度；用户界面若用度，必须在接口边界显式换算。
- 每个示例开头说明 SI 单位、时间步长、坐标系（ENU/NED/机体系/速度系）和正方向；不要只写“惯性系”。
- 角度差应用 `wrap_pi()` 或明确的连续角度表示，不能直接对跨越 ±π 的角度相减。
- 明示每个矢量属于哪个坐标系；旋转矩阵方向（A→B 或 B→A）写在函数名/注释中。所有叉乘顺序均用可手算的例子核对。
- 区分角速度 rad/s、线速度 m/s、角加速度 rad/s²、线加速度 m/s²；严禁把“过载 g”与 SI 加速度混为一谈。

### 3. 接口与错误处理

- 示例提供确定的输入、输出和状态；推荐 `int function(const Input *in, State *state, Output *out)`，返回明确状态码，不通过全局变量暗传状态。
- 指针先检查 `NULL`；浮点输入检查 `isfinite()`；除法前判断分母阈值；平方根、反三角函数等先验证定义域。
- 参数无效时返回错误码并给出安全、可观察的行为；不要将 NaN 静默替换成看似正常的控制量。
- 初始化所有状态；区分首次调用、正常周期调用、复位和故障降级。讲清楚状态量由调用者保存还是函数内部静态保存。
- 限幅函数需处理 `min > max` 等错误配置；报告原始命令、限幅后命令及饱和标志，便于日志诊断。
- 示例如需模拟，应使用固定步长和明确积分方法，并提醒离散步长过大可能造成不稳定或失真。

### 4. 工程实现必须讲明的模式

- **幅值限制与速率限制是两件事**：幅值限制约束可用范围；速率限制约束相邻周期变化。速率限制需要上一周期值、采样周期和复位语义。
- **命令整形**：角度/加速度阶跃可通过斜坡、速率限制或低通环节整形；说明滤波时延和相位滞后的代价。不得将平滑写成无代价的“万能修复”。
- **抗积分饱和**：若 PID 积分器继续累计而执行器已饱和，会导致超调与恢复慢；说明条件积分或反算回馈的适用方式，并明确限幅发生在哪一级。
- **抖振来源区分**：噪声、离散采样、差分放大、硬切换、饱和和模型查表跳变是不同成因；每种缓解方法需对应具体成因，并说明代价。
- **气动查表**：表的自变量、单位、网格排序、插值方法、表外行为、构型/马赫/高度有效范围必须定义。不能静默外推；越界要报告状态并采用约定的钳位、降级或失效处理。
- **前馈与反馈**：查表/模型反解属于前馈或配平映射；反馈用于纠正误差和扰动。PID 不能保证指令可达，也不能替代多输入控制分配或约束优化。
- **离散实现**：固定采样周期或显式传入 `dt`；对 `dt <= 0`、过大间隔、丢帧和重复时间戳有规定。微分项需滤波，且其离散实现不应将噪声放大问题略去。

### 5. 每章代码与排错的固定格式

每章的代码框应依次包含：

1. 本例要解决的问题、适用前提和明确不覆盖的内容。
2. 输入输出及单位/坐标约定。
3. 核心公式到代码的逐步对应。
4. 完整可编译 C99 示例和编译命令。
5. 一组可复现的输入及预期输出/合理范围。
6. 关键变量日志建议（原始指令、限幅后指令、误差、饱和标志、状态码）。
7. “现象—优先检查—原因—验证方法—修正办法”排错表。

示例代码注释可按块逐步讲解，但对坐标变换、限幅、单位换算、边界保护和状态更新等关键行要具体说明。不得用“检查代码”“调参数看看”代替可操作步骤。

## 二、跨章节高风险理论与实现审查清单

### 几何与相对运动

- 相对量定义必须全书一致，例如 `r = r_target - r_vehicle`、`v_rel = v_target - v_vehicle`；若采用相反定义，要明确调整所有后续公式。
- 闭合速度符号需通过“距离正在缩短”的例子校验，不能把 `-dot(r,v_rel)/|r|` 的符号写反。
- LOS 角速度的二维符号和三维叉乘顺序要用简单正交向量验证；奇异点（距离接近零、仰角极点）需说明。
- 坐标变换应验证正交性、行列式和往返变换；欧拉角顺序不得含糊。

### 制导律与阶段逻辑

- 比例导引表达式必须写清导航比定义、闭合速度/目标相对运动假设、加速度方向约束和单位。
- 不能将理想运动学下的解析结论直接说成带气动、延迟和执行器约束的普遍保证。
- 目标机动补偿、导航比取值、拦截可达性需标注假设；不把特定经验值表述为通用常数。
- 交接逻辑需有进入/退出条件、滞回或驻留时间处理，避免阈值附近频繁切换；明确状态估计或指令如何连续初始化。

### BTT/STT 与气动控制分配

- BTT 的横向/法向加速度分配必须说明小侧滑、升力主导等近似和滚转角定义；`atan2` 参数次序、轴向符号、象限与角度包络需验证。
- 由期望加速度反解攻角前需检查动压、质量、升力曲线斜率、攻角包线及解是否存在；不要假设总有唯一解。
- STT 依靠侧滑相关侧力实现横向力，不能把 BTT 的升力倾斜公式直接套用；需依赖气动构型和侧力模型，说明局部可逆条件及耦合影响。
- 气动系数的轴系、正负号、动压定义和参考面积应明确；坐标轴不同会改变气动力符号和分量。
- 期望角度的周期性处理、最短转向方向、滚转速率/攻角变化率及执行器限幅应分开处理。

### 估计、滤波与鲁棒性

- KF 需核对状态维度、`F/H/Q/R` 维数、噪声定义、采样时间离散化和协方差对称正定；不能只给出公式不给矩阵含义。
- 角度观测创新需 wrap；直接做普通差值可能产生接近 `2π` 的假误差。
- 滑模控制要说明匹配扰动等条件、边界层/饱和近似与抖振权衡；不能承诺真实模型下严格有限时间收敛而不列假设。
- 所谓鲁棒界必须注明是已知上界、估计值还是经验参数；不要将仿真中的稳定现象包装成理论保证。

### 最优/MPC/学习与 C 部署

- 最优控制中的 Hamiltonian 符号、协态边界条件、最小化/最大化约定要前后一致。
- MPC 必须说明优化变量、预测模型、约束和不可行/超时策略；讲解模型预测不等于保证在线求解成功。
- 学习策略部署前需明确训练/推理边界、观测归一化、动作缩放和安全过滤；C 代码不能暗示可直接在飞控周期内训练大型网络。
- C 示例须核查数组边界、整数/浮点类型、溢出、`math.h` 函数单位、`atan2(y,x)` 次序、`fmin/fmax` 与 NaN 行为。
- 代码展示的“安全输出”只对其明确限定的教学模型有效；不能被描述为真实系统安全认证。

## 三、建议每章通用排错流程

1. **先核输入**：打印原始状态、时间戳、单位、参考系标识和有效标志，查 NaN/Inf/突跳。
2. **再核几何**：用一组手算的小数值例子检查向量方向、坐标变换和正负号。
3. **拆中间量**：分别记录期望量、限幅前值、限幅后值、速率限制后值和最终输出，不要只看最终轨迹。
4. **单模块替换**：用已知输入绕过传感器或气动模块，区分算法错误和数据接口错误。
5. **固定时间步**：检查采样周期、时间单位、丢帧、积分步长和滤波系数是否匹配。
6. **先静态后闭环**：先测函数边界和表格插值，再测试单环，再接全系统；每次只改变一个因素。
7. **注入故障**：至少覆盖输入越界、缺测/延迟、饱和、`dt` 异常、气动表越界和状态复位。
8. **比较可重复结果**：固定初值和配置；记录代码版本、参数、日志与终止原因，避免凭动画判断正确性。
