# 第1章 导弹 GNC 系统与任务流程

> 本章从“高频感知（导航）—实时决策（制导）—物理执行（控制）”讲起。对象统一为导弹或动能拦截器，任务指标是减小脱靶量、满足终端落角，并在动压、过载和舵机能力内完成拦截。约定 SI 单位；内部角度统一用 rad。

## 本章导航

**前置知识：**高中力学、向量、导数和基本反馈概念即可。
**学完后应能：**

1. 用一句话分别说明导航、制导和控制解决什么问题；
2. 画出从传感器量测到舵面动作的闭环信号流；
3. 解释为什么“制导律算对了”仍可能脱靶；
4. 读懂后续章节反复出现的状态、参考量、指令、约束和时间戳。

全书的核心问题可以写成一条因果链：

\[
\text{量测}\rightarrow\text{状态估计}\rightarrow
\text{制导指令}\rightarrow\text{姿态/气动指令}\rightarrow
\text{执行机构}\rightarrow\text{弹道变化}\rightarrow\text{新量测}.
\]

任何一环存在坐标错误、延迟、饱和或模型偏差，都会沿闭环传播。学习制导时不要只记某条公式，而要始终追问：它使用什么信息、输出什么物理量、下游能否实现、失败时如何发现。

## 先统一语言：全书坐标系与角度约定

后文若未另行声明，一律采用下表；局部章节若使用 NED 或其他轴系，必须先明确给出变换关系。所有坐标系均为**右手系**，角度内部以 rad 计算、页面可用 ° 显示，正转方向服从右手定则。

| 名称 | 轴与原点 | 本书中的用途 |
|---|---|---|
| 导航/惯性系 $n$（局部 ENU） | 原点为场景参考点；$x_n=E$ 向东，$y_n=N$ 向北，$z_n=U$ 向上 | 弹目位置、速度、轨迹和制导加速度的默认表达系 |
| 机体系 $b$ | 原点在弹体质心；$x_b$ 向前，$y_b$ 向右，$z_b$ 向下 | 姿态、角速度、气动力和舵面接口 |
| 速度系 $v$ | $x_v$ 沿速度；$y_v$ 取局部右侧法向；$z_v=x_v\times y_v$ | 把制导加速度分解为两个速度法平面分量；当速度近于铅直时须另选连续基向量 |
| 视线系 $\ell$ | 原点在导弹；$x_\ell=\hat{\mathbf r}$ 从导弹指向目标，另两轴位于 LOS 法平面 | 导引头离轴角、LOS 转动和末制导几何 |

全书统一用 $C_A^B$ 表示“把 A 系分量变成 B 系分量”的被动坐标变换：

\[
\mathbf q^B=C_A^B\mathbf q^A.
\]

基准检查始终使用同一个向量：若 $\mathbf e_x^A=[1,0,0]^T$，则 $C_A^B\mathbf e_x^A$ 必须等于 $C_A^B$ 的第一列；正交旋转矩阵才满足 $(C_A^B)^{-1}=(C_A^B)^T$。

### 角度零点、正方向和取值

| 角度 | 定义 | 零点与正方向 |
|---|---|---|
| 方位角 $\mathrm{az}$ | LOS 或任意向量在 EN 平面的方向 | 从北 $+y_n$ 起，向东 $+x_n$ 为正：$\operatorname{atan2}(E,N)$ |
| 仰角 $\mathrm{el}$ | 向量相对 EN 水平面的抬升角 | 水平为 0，向上为正：$\operatorname{atan2}(U,\sqrt{E^2+N^2})$ |
| 航向角 $\chi$ | 速度水平投影的方位角 | 与方位角相同，北为 0、向东为正 |
| 航迹倾角 $\gamma$ | 速度相对水平面的倾角 | 水平为 0，爬升为正 |
| 偏航/俯仰/滚转 $\psi,\theta,\phi$ | 机体相对导航系的姿态欧拉角 | 采用规定旋转序列时才有唯一含义；本文接口必须同时携带序列，不把它们与 $\chi,\gamma$ 混用 |
| 攻角 $\alpha$ | 速度相对机体纵向在 $x_bz_b$ 平面的夹角 | 机头相对来流抬起为正 |
| 侧滑角 $\beta$ | 速度相对机体对称面的侧向夹角 | 正号按 $+y_b$ 分量定义；接入外部气动数据时须核对其来流/速度定义 |
| 倾侧角 $\phi_v$ | 速度法平面内的升力方向角 | 零倾侧时升力取局部向上方向；绕 $+x_v$ 按右手定则为正 |
| 离轴角 $\theta_{off}$ | 弹体/导引头视轴 $\hat{\mathbf b}$ 与 LOS 的夹角 | $\arccos(\hat{\mathbf b}\cdot\hat{\mathbf r})\in[0,\pi]$，只表示圆锥夹角，不含方位符号 |
| 导弹前置角 $\eta_M$ | 导弹速度与 LOS 的夹角 | $\arccos(\hat{\mathbf v}_M\cdot\hat{\mathbf r})$；是三维夹角，不应直接用两个方位角相减代替 |
| 目标迎向角 $\eta_T$（target aspect） | 目标速度与“目标指向导弹”方向的夹角 | $\arccos(\hat{\mathbf v}_T\cdot(-\hat{\mathbf r}))$；$0$ 表示迎向导弹，$\pi$ 表示同向逃逸；它不是目标姿态欧拉角 |
| 期望终端航向/航迹倾角 $\chi_f,\gamma_f$ | 共同定义期望终端速度方向 $\hat{\mathbf d}_f$ | 分别按 ENU 的航向角与航迹倾角定义；“落角”若相对地面或目标表面定义，必须另外说明参考面和正方向 |
| 终端方向误差 $\varepsilon_f$ | 终端速度方向与期望终端方向的夹角 | $\arccos(\hat{\mathbf v}_M(t_f)\cdot\hat{\mathbf d}_f)$；它与位置脱靶量是两个独立指标 |

相对量固定定义为从导弹指向目标：$\mathbf r=\mathbf r_T-\mathbf r_M$、$\mathbf v_r=\mathbf v_T-\mathbf v_M$；接近时闭合速度 $V_c=-\dot R>0$。三维制导计算优先使用 $\hat{\mathbf r}$ 和 $\boldsymbol\omega_{LOS}=(\mathbf r\times\mathbf v_r)/R^2$，方位角和仰角主要用于显示，避免在天顶附近把角度参数化奇异性带入制导律。

![三维制导坐标系与角度总图](assets/guidance-angles-overview.svg)

读图时应先判断角属于哪一层：$\lambda_{az},\lambda_{el}$ 描述 **LOS 在导航系中的显示方向**；$\boldsymbol\omega_{LOS}$ 描述 **LOS 在三维空间的瞬时转动**，是 PN 的直接输入；$\eta_M,\eta_T,\theta_{off}$ 是 **两个方向矢量之间的几何夹角**；$\chi,\gamma$ 描述速度方向；$\psi,\theta,\phi$ 描述机体姿态；$\alpha,\beta,\phi_v$ 用于把制导加速度交给气动与控制系统；$\varepsilon_f$ 则用于检查终端方向约束。它们不能因为都以度或弧度表示就互相代换。

### 四个可以立即复算的例子

1. **点积：**取 $\mathbf a=[3,4,0]^T$、$\mathbf b=[1,0,0]^T$，则 $\mathbf a^T\mathbf b=3$，且 $\|\mathbf a\|=5$。
2. **叉积：**$[1,0,0]^T\times[0,1,0]^T=[0,0,1]^T$；交换次序，结果反号。
3. **矩阵：**令 $C_A^B=\begin{bmatrix}0&-1&0\\1&0&0\\0&0&1\end{bmatrix}$，则 $[1,0,0]^T$ 在 B 系中的分量为 $[0,1,0]^T$；再乘 $(C_A^B)^T$ 应回到原向量。
4. **协方差：**若 $P=\operatorname{diag}(4,9)$，两个状态的标准差分别为 2 和 3；非对角元为零只表示在线性二阶统计意义下不相关，并不自动证明独立。

若四个结果不能独立算出，先补齐相应基础再进入第2章；若只希望理解概况，可以先记住每个量的物理含义。

量纲是最便宜的检查工具。例如 $V_c\dot\lambda$ 的单位是 $(\mathrm{m/s})(\mathrm{rad/s})$。弧度视为无量纲，因此结果为 $\mathrm{m/s^2}$，可以作为加速度；若推导得到 $\mathrm{m/s}$，就说明遗漏了时间尺度。

一阶执行机构常写成

\[
\tau\dot y+y=u.
\]

经过一个时间常数 $\tau$，输出约完成最终变化的 63%；约经过 $4\tau$ 才基本稳定。带宽越高通常跟随越快，但噪声和未建模高频动态也更容易进入闭环。纯延迟则表示一段时间内完全得不到最新信息，不能简单等同于一阶滞后。

## 1.1 三个模块不要混为一谈

- **导航/状态估计**：融合惯导、卫星组合导航更新、数据链目标信息和导引头量测，形成带时间戳与协方差的弹目状态估计。
- **制导**：依据弹道阶段和拦截几何生成期望法向加速度、速度方向或末端落角参考，其直接目标是压缩零控脱靶量。
- **飞行控制**：把期望运动量变成攻角、倾侧角和舵偏命令，并处理大过载、舵机幅值/速率饱和及弹体耦合动态。

工程接口要写清参考系、单位、时间戳、有效标志和饱和状态。制导器不应把“无效/过期数据”当作正常测量继续计算。

## 1.2 离散周期中的信号流

弹载计算机按确定的周期表执行导航、制导与控制任务。导航/姿态环常快于制导环，但每条跨周期数据都必须带时间戳。末段闭合速度高，数毫秒的调度抖动也会转化为状态传播误差；若周期抖动不可忽略，应使用实际 $\Delta t=t_k-t_{k-1}$，并对异常值拒收或降级。

一个通用闭环可写为

\[
\hat{x}_k=\mathcal{E}(y_{0:k}),\quad
u_k=\pi(\hat{x}_k,r_k),\quad
u^{\rm safe}_k=\operatorname{limit}(u_k),\quad
u^{\rm plant}_k=\mathcal{C}(u^{\rm safe}_k).
\]

这里 $y$ 是测量，$\hat{x}$ 是估计状态，$r$ 是任务参考，$\pi$ 是制导律，`limit` 是指令幅值/速率保护，$\mathcal C$ 是飞行控制。限幅不能掩盖不可达命令：应同时记录原始命令、限幅后命令、限幅标志与误差。

## 1.3 先定接口，再写算法

推荐每个周期使用明确的数据包：

| 字段 | 含义 | 必须约定 |
|---|---|---|
| `time_s` | 状态时间戳 | 秒；单调递增 |
| `pos_m[3]` | 位置 | 参考系、轴序、m |
| `vel_mps[3]` | 速度 | 同一参考系、m/s |
| `valid` | 数据有效 | 无效时采取何种降级 |
| `quality` | 估计质量 | 范围与阈值 |
| `cmd` | 期望加速度等 | 坐标系、单位、幅值和速率限制 |

初期建议以单一右手惯性直角系做教学模型。后续引入地球曲率、地球自转或高空环境时，再扩展地固/惯性变换，不能悄悄更换坐标意义。

## 1.4 C 实现：周期接口、数据有效性与命令限幅

下面示例可保存为 `ch1.c`，使用 `cc -std=c99 -Wall -Wextra -pedantic ch1.c -lm -o ch1` 编译运行。这里演示导弹制导加速度接口保护，不代表任何具体型号的制导律。

```c
#include <math.h>      /* isfinite、sqrt 等数学函数 */
#include <stdbool.h>   /* bool 类型 */
#include <stdio.h>     /* printf */

typedef struct {       /* 三维向量：本例统一采用同一右手坐标系 */
    double x, y, z;    /* 分量的单位由字段名或接口约定说明 */
} Vec3;

typedef struct {       /* 导航/估计输出的数据包 */
    double time_s;     /* 状态对应的时间戳，单位 s */
    Vec3 pos_m;        /* 位置，单位 m */
    Vec3 vel_mps;      /* 速度，单位 m/s */
    bool valid;        /* 上游明确置位的数据有效标志 */
} State;

typedef struct {       /* 制导模块输出及保护状态 */
    Vec3 accel_mps2;   /* 期望加速度，单位 m/s^2 */
    bool saturated;    /* 本周期是否发生幅值限幅 */
} GuidanceOutput;

static bool finite_vec(Vec3 v) { /* 拒绝 NaN 或无穷输入 */
    return isfinite(v.x) && isfinite(v.y) && isfinite(v.z);
}

static GuidanceOutput limit_accel(Vec3 a, double max_mps2) {
    GuidanceOutput out = {a, false};            /* 默认不改变输入 */
    double mag = hypot(hypot(a.x, a.y), a.z);     /* hypot 避免平方和溢出或下溢 */
    if (!isfinite(mag) || !isfinite(max_mps2) || max_mps2 <= 0.0) {
        out.accel_mps2 = (Vec3){0.0, 0.0, 0.0}; /* 参数非法时给安全默认值 */
        out.saturated = true;                    /* 同时报告保护触发 */
        return out;
    }
    if (mag > max_mps2) {                        /* 只在超过模长上限时缩放 */
        double scale = max_mps2 / mag;            /* 保持方向，缩小幅值 */
        out.accel_mps2.x *= scale;
        out.accel_mps2.y *= scale;
        out.accel_mps2.z *= scale;
        out.saturated = true;
    }
    return out;
}

int main(void) {
    State s = {1.0, {100.0, 0.0, 20.0}, {10.0, 1.0, 0.0}, true};
    Vec3 raw_cmd = {180.0, -90.0, 0.0};          /* 末段示例指令，约 20.5 g */
    if (!s.valid || !isfinite(s.time_s) || !finite_vec(s.pos_m) || !finite_vec(s.vel_mps)) {
        puts("状态无效：本周期不运行制导计算");
        return 1;
    }
    GuidanceOutput y = limit_accel(raw_cmd, 30.0 * 9.80665); /* 30 g 过载保护 */
    printf("a=(%.3f, %.3f, %.3f), saturated=%d\n",
           y.accel_mps2.x, y.accel_mps2.y, y.accel_mps2.z, y.saturated);
    return 0;
}
```

注意：真实模块还需处理状态过期、坐标系标识、命令速率、执行机构反馈和故障降级。上述限幅在向量模上限下保持三轴指令比例；若各轴具有不同边界，必须采用逐轴或约束分配方式，二者不是同一个限幅定义。

## 1.5 常见故障与排查步骤

| 现象 | 常见原因 | 按顺序排查 |
|---|---|---|
| 指令突然为零 | `valid=false`、NaN 检测触发、保护逻辑默认值 | 打印状态有效位、每个输入及保护原因码；定位第一个非有限数 |
| 命令长期贴着上限 | 任务不可达、单位错误、限幅过低或反馈方向错误 | 对照限幅前后命令；核实单位；在简单初值下检查误差符号 |
| 仿真每步结果不一样 | 未固定初始状态/随机种子，或使用未初始化内存 | 记录完整输入快照；清零状态；固定随机种子 |
| 首周期出现巨大导数 | 差分前没有有效上一时刻，或时间戳回退 | 初始化标志单独管理；检查 `dt>0` 且处于允许范围 |
| 离线仿真正常、实机异常 | 采样周期、延迟、坐标约定、数据有效语义不一致 | 记录时间戳和输入输出；重放原始日志；逐接口对照单位/坐标系 |

**最笨但有效的排错法**：每周期记录“时间戳、输入状态、原始制导命令、限幅后命令、保护标志、下游反馈”。先找到第一次异常的周期，再从该周期向前检查，不要只盯着最终偏差。

## 1.6 本章实验

加入可调制导周期、数据链延迟、导引头失锁和 20g～40g 加速度上限。分别观察信息过期时的零控脱靶量增长、限幅触发比例，以及周期变慢时末段视线角速率的发散趋势。实验应同时展示脱靶量、原始/整形后指令和保护标志，而不只是弹道图。

## 1.7 一次完整任务怎样运行

典型任务可分为初始对准与发射、中段飞行、导引头搜索与截获、末制导和终止判定。阶段划分不是为了画流程图，而是因为可用信息和控制目标发生了变化：

| 阶段 | 主要信息 | 制导关注点 | 主要风险 |
|---|---|---|---|
| 初始段 | 发射点、目标先验、惯导 | 建立安全可行弹道 | 初始误差、姿态瞬态 |
| 中段 | 惯导、卫星更新、数据链 | 更新预测拦截点，保留末端能量 | 数据延迟、目标机动 |
| 搜索/截获 | 导引头视场与量测质量 | 把目标稳定送入跟踪门 | 假目标、失锁、状态跳变 |
| 末制导 | 高频 LOS 与相对状态 | 快速压低脱靶量并满足落角 | 过载饱和、时延、噪声 |
| 终止 | 距离、闭合速度、任务逻辑 | 冻结或结束制导输出 | 近距奇异、误判终止 |

这也解释了为什么不存在一条从发射到终端都最合适的制导律：远距离时预测误差占主导，近距离时视线角速率和执行机构带宽占主导。

## 1.8 本章小结与基础自测

### 计算与编程练习

> **实验能力边界：** 标注为“网页可完成”的内容仅使用本页实际显示的控件；凡要求新增制导律、噪声、延迟或约束开关而页面未显示对应控件，均标注为“需自行编程”，不应寻找不存在的滑块。

- **基础题：**不用公式，用自己的话描述导航、制导、控制各自的输入和输出。
- **计算题：**若闭合速度为 400 m/s，数据延迟 50 ms，估算延迟期间传播距离。
- **编程题：**为 `GuidanceInput` 增加时间戳和数据年龄检查，并写出过期输入测试。
- **实验步骤：**先把延迟设为零，只改变反馈增益；再固定增益逐步增加延迟。观察超调和稳定时间，不能从该简化实验推断真实导弹稳定裕度。

1. 数据链目标位置已经过期 0.5 s，但制导器仍把它当作当前状态，会首先污染哪一层？
2. 制导器输出 35g，而飞控和气动只能实现 20g，此时继续提高制导增益是否有意义？
3. 为什么状态有效标志、时间戳和坐标系标签与位置数值本身同样重要？

**本章结论：**GNC 不是三个独立算法，而是不同带宽、不同信息源和不同物理约束组成的闭环系统。后续每学习一个公式，都应把它放回这条闭环链路中。

### 参考答案与判断依据

1. 首先污染导航/状态估计层，因为“旧位置”被错误标成当前状态；随后预测拦截点和制导指令都会偏离。正确接口必须同时传数值、量测时间和数据年龄。
2. 没有意义。实际加速度仍被限制在 20g，继续增益只会延长饱和时间、增加积分累积或指令抖动。应检查任务可达性并重新分配约束。
3. 数值只有在“何时、在哪个坐标系、是否可信”确定后才有物理意义。同一个三元组在 ENU、NED 或弹体系中代表不同方向，过期状态也不代表当前状态。
