# 第6章 指令整形、限幅与执行机构

> 制导指令不是理想数学信号。真实飞行控制系统受幅值、变化率、带宽、延迟、量化和模式切换影响。本章讨论如何把可行指令送入下游控制器，并避免把饱和误认为“控制器不够强”。

## 6.1 限幅不是一个函数就结束

至少区分下列约束：

- **幅值限制**：如 \(|\phi|\le\phi_{max}\)、\(|\alpha|\le\alpha_{max}\)、\(|a_c|\le a_{max}\)。
- **变化率限制**：如 \(|\dot\phi|\le r_{\phi,max}\)，避免指令跃变超过滚转/舵机能力。
- **加加速度/jerk 限制**：限制加速度变化速度，降低激励结构模态或激烈瞬态的风险。
- **包线/状态相关限制**：限制值可能随速度、动压、迎角、构型变化，不应总用固定常数。
- **耦合约束**：多个轴的合成加速度、舵面余量或功率可能受共同限制。

执行次序需经设计确认。一个常用的简化流水线是：先生成可达命令，再施加幅值约束，接着做速率限制，最后转换为下游接口量；如果约束本身相互耦合，应做联合约束求解，而非每轴独立裁剪。

## 6.2 阶跃指令为什么会出问题

若理想指令在一个采样周期内从 \(u_0\) 跳到 \(u_1\)，其理论变化率趋于无穷。物理执行机构无法瞬时跟随，通常会饱和并产生滞后。对 BTT 而言，倾侧角阶跃可能要求无法实现的滚转率；对攻角指令而言，阶跃可能令舵面短时饱和、引入大瞬态或激发未建模动态。

最低限度的整形是速率限制：

\[
u_k=u_{k-1}+\operatorname{clip}(u_{cmd,k}-u_{k-1},-r_{max}\Delta t,r_{max}\Delta t).
\]

更平滑的做法是二阶参考模型：

\[
\dot u_r=v_r,\qquad \dot v_r=\operatorname{clip}(\omega_n^2(u_c-u_r)-2\zeta\omega_n v_r,-a_{r,max},a_{r,max}),
\]

其中 \(u_r\) 是送给跟踪环的平滑参考，\(v_r\) 是参考变化率。该模型只用于参考整形，参数需依据飞控带宽和允许响应确定，不能随意设得比执行机构快很多。

倾侧角还需处理周期性：先算最短角差，再对角差做限速，再加回当前角；不能先把目标角粗暴裁到区间后直接相减。若任务要求特定转向方向或禁止穿越某些姿态区间，还要在模式管理层明确处理。

## 6.3 饱和与 PID 积分 windup

考虑 PI 控制器

\[
u_{raw}=K_pe+I,\qquad u=\operatorname{sat}(u_{raw}),\qquad \dot I=K_i e.
\]

若执行器长期饱和，误差仍推动积分器增长；误差反向后，积分量要先“退回来”，造成恢复慢、超调大。常见处理方式有：

1. **条件积分**：只有当未饱和，或误差推动输出离开饱和边界时，才积分。
2. **反算抗饱和**：使用实际受限输出与原始输出差值回馈积分状态。
3. **积分限幅/泄漏**：限制积分量，必要时在模式切换时按规则重置或跟踪初始化。

必须明确 PID 的输出是什么量、限幅发生在哪一级、反馈是舵机命令还是实际舵偏。只在显示层裁剪，而控制器内部仍积分到无限大，不算抗饱和。

## 6.4 离散采样、微分噪声与抖振

制导律的采样周期、状态估计周期和飞控周期可能不同。把较慢更新的指令当作每个高频周期都重新计算，会导致重复量化、数值差分噪声或异步数据竞争。应为每个输入标注时间戳、有效期和更新频率；过期目标状态要明确保持、预测或进入安全降级。

抖振来源应分类排查：

- 传感器噪声经差分放大；
- 量化、采样周期过长或时间戳抖动；
- 阈值/模式切换缺少滞回；
- 查表噪声、插值不连续；
- 高增益控制器追逐执行器死区/间隙；
- 滑模符号函数在边界附近快速切换。

相应手段包括：对合理带宽内信号滤波、对模式切换加滞回、用连续近似或边界层减轻高频切换、修复插值连续性、正确处理死区和速率限制。滤波会带来相位滞后；不能为了“曲线好看”把延迟引入闭环而不重新评估稳定性。

## 6.5 C 示例：周期角速率限制与安全输出

本例演示弧度内部表示、最短角差、采样周期检查与速率限制。工程代码应把 `last_rad` 存在每个飞行器实例状态中，不可用全局变量共享。

```c
#include <math.h>       // 提供 sin、cos、atan2、isfinite
#include <stdbool.h>    // 提供 bool 类型
#include <stdio.h>      // 提供 printf

#define PI 3.14159265358979323846  // 圆周率常量

typedef struct {                    // 声明一个限速器的持久状态
    double last_rad;                // 上一周期输出，单位 rad
    bool initialized;               // 状态是否已初始化
} AngleLimiter;

static double wrap_pi(double x) {   // 将角度差包裹到 [-pi, pi]
    return atan2(sin(x), cos(x));  // 三角函数形式能正确处理跨越 ±pi
}

static double clamp(double x, double lo, double hi) { // 通用区间限制函数
    if (x < lo) return lo;          // 低于下限则取下限
    if (x > hi) return hi;          // 高于上限则取上限
    return x;                       // 否则不改变输入
}

static bool rate_limit_angle(AngleLimiter *s, double target_rad,
                             double max_rate_rad_s, double dt_s,
                             double *output_rad) {
    if (s == NULL || output_rad == NULL) return false; // 拒绝空指针，避免非法内存访问
    if (!isfinite(target_rad) || !isfinite(max_rate_rad_s) || // 拒绝 NaN/无穷大输入
        !isfinite(dt_s) || max_rate_rad_s < 0.0 || dt_s <= 0.0) return false;
    if (!s->initialized) {          // 首次调用时不能读取未初始化历史值
        s->last_rad = wrap_pi(target_rad); // 将初值规范到 [-pi, pi]
        s->initialized = true;      // 标记状态已可用
    }
    double err = wrap_pi(target_rad - s->last_rad); // 取最短周期角差
    double max_step = max_rate_rad_s * dt_s; // 本周期最多允许变化的角度，rad
    double step = clamp(err, -max_step, max_step); // 限制每周期增量
    s->last_rad = wrap_pi(s->last_rad + step); // 更新持久状态并规范角度
    *output_rad = s->last_rad;      // 把输出写回调用者给定的内存
    return true;                    // 表示计算成功
}

int main(void) {                    // 独立运行示例
    AngleLimiter limiter = {0.0, false}; // 初次状态设为未初始化
    double command_rad = 179.0 * PI / 180.0; // 命令角先从度转换为弧度
    double output_rad = 0.0;        // 准备接收限速器输出
    if (!rate_limit_angle(&limiter, command_rad, 30.0 * PI / 180.0, 0.02, &output_rad)) {
        puts("输入错误：检查指针、单位、dt 和角速度上限"); // 失败时输出排查提示
        return 1;                    // 返回错误状态码
    }
    printf("输出角 = %.3f deg\n", output_rad * 180.0 / PI); // 仅显示时转换为度
    return 0;                        // 正常结束
}
```

编译：`cc -std=c11 -Wall -Wextra -pedantic angle_limit.c -lm -o angle_limit`。例如上次输出为 +179°、目标为 −179° 时，最短角差是 +2°，而不是 −358°。本实现默认允许跨过 ±π 边界；如任务指定转向方向，应由上层模式逻辑提供方向约束。

## 6.6 指令链路的接口约定

每个指令接口至少应定义：信号名称、数值单位、参考系、正方向、采样周期、时间戳、有效范围、变化率范围、超时策略、失效值和状态码。推荐同时传递：`value`、`valid`、`saturated`、`source_time`、`reason_code`。不要只传一个浮点数，让下游无法区分“真实零指令”和“数据失效后填的零”。

C 实现中，角度建议在内部统一使用 rad，界面/报告才转换为 deg；输入解析处只转换一次，并在变量名或类型注释中写明单位（如 `bank_rad`）。速度、距离和时间分别用 m/s、m、s；角度速率用 rad/s；动压用 Pa；力用 N。若项目必须使用其他单位，应在边界层显式转换，禁止同一变量在不同函数中含义不同。

## 6.7 常见错误与逐步排查

| 现象 | 常见原因 | 排查步骤 | 修正办法 |
|---|---|---|---|
| 指令限幅后仍持续“越积越大” | 限制在控制器之后，积分状态未感知饱和 | 同屏记录原始输出、限幅输出、执行器反馈、积分项；看饱和期间积分是否继续增长 | 条件积分或反算抗饱和；明确反馈实际执行量 |
| 角度每过 180°就跳变 | 角度差直接相减或归一化位置错误 | 用 179°→−179°、−179°→179°两个测试用例 | 先算包裹后的最短角差，再限变化率 |
| 速率限制随帧率变化 | dt 固定写死、单位把 deg/s 当 rad/s | 打印时间戳差和 `max_rate*dt`；改变仿真步长重复测试 | 使用真实采样间隔；统一单位；限制异常 dt |
| 过滤后振荡更严重 | 滤波延迟降低相位裕度，或滤波放错闭环位置 | 记录未滤波/滤波信号延迟；改变截止频率并看相位和响应 | 按闭环带宽设计滤波；避免盲目加大平滑强度 |
| BTT 滚转方向交替 | 目标方位噪声、零加速度附近方向无定义、切换无滞回 | 看目标向量模值、角差、模式标志；在零附近注入小噪声测试 | 零向量时保持有效参考；设置进入/退出阈值和滞回 |
| 攻角超限但状态仍显示正常 | 只限制舵机命令，没有监控实际迎角/包线 | 同时记录 alpha_cmd、alpha_est、舵偏、动压、包线标志 | 限制应在指令层和监控层都可见；越界触发保护状态 |
| 某一飞行器影响其它对象的限速状态 | 多实例共用静态/全局变量 | 并行运行两个不同目标，检查输出是否串扰 | 状态放到每个对象结构体；函数保持可重入 |
| C 程序偶发输出 NaN | 除零、无效表值、未初始化状态、溢出 | 对输入输出做 `isfinite`；用调试日志定位首次出现 NaN 的模块 | 加边界检查、初始化所有状态、失败时返回显式状态码 |
| 仿真步长改变后行为完全不同 | 离散控制没有按 dt 缩放，积分/微分实现错误 | 用 dt、dt/2、dt/4 做对比；检查积分是否乘 dt、微分是否除 dt | 使用真实 dt；在多采样率接口上做时间戳同步 |

## 6.8 傻瓜式调试顺序

遇到“指令看起来不对”时，不要立刻改增益。按以下顺序逐层看信号：

1. **输入是否可信**：检查有效标志、时间戳、单位、NaN/Inf。
2. **坐标与符号是否正确**：用手算的小例子验证一次变换和正方向。
3. **原始制导指令是否合理**：查看未限幅加速度/角度，不先看最终舵面量。
4. **是否可达**：同时看动压、气动表边界、迎角/侧滑/倾侧角和舵偏余量。
5. **整形器做了什么**：并排画原始指令、幅值限制后、速率限制后、实际状态。
6. **是否饱和或延迟**：记录执行机构请求、实际位置、速率和饱和标志。
7. **反馈环是否正常**：检查误差、比例项、积分项、微分项和抗饱和信号。
8. **离散实现是否一致**：确认 dt、更新频率、时间戳、任务调度和状态初始化。
9. **用最小案例复现**：固定状态、关闭非必要环节，一次只加回一个模块。
10. **保存故障证据**：记录参数、版本、随机种子、最后有效输入和故障码，确保能复现。

### 本章小结

限幅、速率限制、滤波和 PID 都会改变闭环行为，必须作为系统的一部分分析与测试。正确工程流程是先验证单位与信号，再检查可达性和饱和，最后才考虑调增益。
