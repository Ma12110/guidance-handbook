# 导弹制导、导航与控制交互手册

面向航空航天、控制及相关专业学习者的中文工程化在线手册。全书以导弹及动能拦截器为统一对象，压缩为 9 章，覆盖 GNC 任务流程、三维相对运动、经典制导、中末制导交接、弹体动力学与 BTT/STT、指令整形、状态估计、最优制导以及硬实时 C 实现。

**GitHub Pages：** https://paoshou-china.github.io/guidance-handbook/

## 章节结构

1. 导弹 GNC 系统与任务流程
2. 坐标系与三维相对运动
3. 经典制导律
4. 中制导、预测与全程交接
5. 弹体动力学、气动模型与 BTT/STT 控制分配
6. 指令整形与执行机构约束
7. 状态估计与鲁棒控制
8. 改进制导律、最优制导与模型预测控制
9. 弹载 C 软件与硬实时工程实现

## 自学定位与最低基础

本手册的“无人讲解可自学”分为两个层级，并不等于零基础即可直接完成工程仿真：

- **目标 A——理解制导概况：**能读懂高中数学、三角函数和基本物理量即可。读完后应能解释导航—制导—控制的分工、LOS 几何、PN 的物理意义以及约束为何会改变结果。
- **目标 B——独立完成仿真：**需要向量与矩阵、常微分方程、反馈控制、概率与协方差的基础，并能阅读 C99 或等价的 Python/Matlab 程序。若这些内容不熟，应先完成第1章预备知识和数值自检题。

开始前建议自检：能计算三维向量点积与叉积；能写出双积分器状态方程；能解释负反馈；能编译并运行一个含 `sqrt` 的 C 程序。不会其中一项不妨碍概览阅读，但会影响独立复现。

## 自学路线

正文按无人讲解场景补充了前置知识、学习目标、物理图景、逐步推导、工程边界、可编译示例、自测题与综合作业。建议按三轮阅读：

1. **第一轮建立全局图景：**阅读第1～4章，理解导航回答“我和目标在哪里”，制导回答“应产生怎样的运动”，控制回答“弹体如何实现该运动”。
2. **第二轮打通物理实现：**阅读第5～7章，把理想指令与气动、执行机构、噪声和延迟联系起来；运行 C 示例并做量纲检查。
3. **第三轮比较高级方法：**阅读第8～9章，比较 PN、APN、ZEM、落角约束、TZC 与 MPC 的任务假设，再完成三维综合作业与故障注入。

初学者可先略读长推导，但不要跳过坐标系、符号、适用假设和饱和处理。建议为每章记录状态量、输入、输出、核心假设、失效条件和一个可复算的数量级例子。能回答章末自测，并解释代码中保护分支为何存在，才算掌握。

九章章末均给出自测参考答案及判断依据，并使用同一组 ENU 三维弹目初始状态贯穿学习。统一算例不是另起一套模型：第1章定义任务与周期，第2章计算相对几何，第3章形成 PN 指令，第4章设计中末制导交接，第5章转换为 BTT/STT 控制需求，第6章加入执行机构约束，第7章处理噪声与延迟，第8章比较改进制导律，第9章完成硬实时实现与验收。读者可以逐章保留计算结果，最终拼成一个完整闭环。

为进一步降低无人讲解条件下的学习门槛，本书还提供：第1章数学与控制预备知识、全书闭环地图和模型层级；第2章二维到三维的过渡、统一符号表和错误公式对照；PN、BTT、卡尔曼增益、ZEM、线性最优落角约束与 TZC 的逐步推导；每章“基础题—计算题—编程题—实验操作卡”；以及第9章统一案例单周期完整标准答案。推荐先手算、再用脚本复算、最后与 C99 中间变量逐项比对。

## 每章的工程化内容

每章均按“物理直觉—原理推导—工程接口—C 语言示例—常见错误与排查—交互实验”组织。C 代码采用 C99 风格，注释解释关键变量、边界判断、单位、最坏执行时间和失败分支；每段代码均为教学级导弹制导算法骨架，不可未经模型核验、半实物仿真和安全审查直接装订。

重点工程主题包括：角度统一用弧度进行内部计算、SI 单位、坐标系和符号约定、指令幅值与速率限制、BTT 倾侧角和攻角指令整形、抖振诊断、气动数据表插值及表外处理、数据有效性检查、故障码与降级策略。BTT/STT 章节分别讲清楚气动反解、前馈和闭环反馈的职责与边界。

贯穿全书的任务语境统一为：惯导/卫星组合导航与数据链完成中段状态更新，导引头稳定截获后转入末制导；制导层以终端脱靶量、落角误差和控制能量为主要指标，控制层显式处理 20g～40g 过载需求、动压包线以及舵机幅值与速率饱和。比例导引按“抑制视线角速度、维持碰撞三角形”的几何机制解释，而不是简单追踪目标当前位置。

第8章在 PN 基线之上进一步讲解 APN、零控脱靶量（ZEM）制导、线性最优落角约束制导、末端零控制指令（TZC）和 MPC。各方法均给出终端约束、闭式公式、适用假设、C99 示例以及过载饱和和 $t_{go}$ 估计带来的工程风险。

## 数学公式约定

- 行内公式使用 `$...$`，例如 `$V_c=-\dot R$`。
- 独立公式使用 `\[...\]`，开始符与结束符必须成对出现并单独占行。
- 向量统一用 `\mathbf r`。坐标变换统一记为 `$C_A^B$`，表示“输入 A 系分量、输出 B 系分量”，即 `$\mathbf v^B=C_A^B\mathbf v^A$`；禁止再使用 `$C^A_B$` 表达同一含义。
- 角度、角速度、速度和加速度分别采用 rad、rad/s、m/s 和 m/s²；工程量级可同时给出 g 或 °/s，但进入算法前统一转换为 SI 单位。
- 公式由 MathJax 渲染。若页面直接显示 `\dot`、`\mathbf` 或孤立的 `\]`，应先检查数学定界符是否缺失，再检查 MathJax CDN 是否加载成功。

公式验收不仅检查定界符，还逐项检查状态定义、正负号、量纲、成立条件和代码对应关系。当前状态见 [`VALIDATION.md`](VALIDATION.md)，尚未完成的项目不会宣称通过。

## 案例、参数与实验边界

- **逐章核对案例：**贯穿第1～9章，用固定 ENU 初始状态逐步核对几何、制导、分配、执行机构和软件中间量。
- **独立综合作业：**用于学生从零搭建三自由度仿真，可改变初始状态和目标机动；它不是逐章案例的续算。两者参数差异在第9章表格中列明。
- 网页操作卡明确标注“网页可完成”或“需自行编程”。网页没有提供的制导律、噪声或约束开关，不再暗示存在相应滑块。
- `$\int u^2dt$` 在本书中称为**控制努力二次指标**。只有补充推力、阻力、质量和速度动力学后，才可讨论真实能耗或末端速度，二者不能直接等同。

## 本地预览与代码示例

网站为静态文件，可在仓库根目录运行：

```sh
python -m http.server 8000 --directory docs
```

然后打开 `http://localhost:8000`。不要直接双击 `docs/index.html`，否则浏览器可能因本地文件访问限制而无法读取章节 Markdown。单文件 C 示例通常可用 `cc -std=c99 -Wall -Wextra -pedantic example.c -lm` 编译。部分平台的数学库链接选项不同；阅读各示例中的编译说明。网页公式依赖 MathJax CDN，首次预览需要能够访问对应 CDN。

## 使用范围

本手册用于导弹制导、弹体动力学与控制理论教学。简化模型和代码示例不代表任何具体型号能力，也不是可直接部署的软件；工程系统还必须依据弹体构型、导引头/惯导/数据链接口、执行机构、气动数据库和试验规范完成逐级验证。
