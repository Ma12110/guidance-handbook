# 导弹制导、导航与控制交互手册

面向航空航天、控制及相关专业学习者的中文工程化在线手册。全书以导弹及动能拦截器为统一对象，压缩为 9 章，覆盖 GNC 任务流程、三维相对运动、经典制导、中末制导交接、弹体动力学与 BTT/STT、指令整形、状态估计、最优制导以及硬实时 C 实现。

**GitHub Pages：** https://paoshou-china.github.io/guidance-handbook/

## 章节结构

1. 导弹 GNC 系统与任务流程
2. 坐标系与三维相对运动
3. 经典制导律
4. 中制导、预测与全程交接
5. 弹体动力学、气动模型与 BTT/STT 控制分配
6. 指令整形与执行机构约束
7. 状态估计与鲁棒控制
8. 改进制导律、最优制导与模型预测控制
9. 弹载 C 软件与硬实时工程实现

## 每章的工程化内容

每章均按“物理直觉—原理推导—工程接口—C 语言示例—常见错误与排查—交互实验”组织。C 代码采用 C99 风格，注释解释关键变量、边界判断、单位、最坏执行时间和失败分支；每段代码均为教学级导弹制导算法骨架，不可未经模型核验、半实物仿真和安全审查直接装订。

重点工程主题包括：角度统一用弧度进行内部计算、SI 单位、坐标系和符号约定、指令幅值与速率限制、BTT 倾侧角和攻角指令整形、抖振诊断、气动数据表插值及表外处理、数据有效性检查、故障码与降级策略。BTT/STT 章节分别讲清楚气动反解、前馈和闭环反馈的职责与边界。

贯穿全书的任务语境统一为：惯导/卫星组合导航与数据链完成中段状态更新，导引头稳定截获后转入末制导；制导层以终端脱靶量、落角误差和控制能量为主要指标，控制层显式处理 20g～40g 过载需求、动压包线以及舵机幅值与速率饱和。比例导引按“抑制视线角速度、维持碰撞三角形”的几何机制解释，而不是简单追踪目标当前位置。

第8章在 PN 基线之上进一步讲解 APN、零控脱靶量（ZEM）制导、线性最优落角约束制导、末端零控制指令（TZC）和 MPC。各方法均给出终端约束、闭式公式、适用假设、C99 示例以及过载饱和和 $t_{go}$ 估计带来的工程风险。

## 数学公式约定

- 行内公式使用 `$...$`，例如 `$V_c=-\dot R$`。
- 独立公式使用 `\[...\]`，开始符与结束符必须成对出现并单独占行。
- 向量统一用 `\mathbf r`，矩阵与坐标变换的上下标方向必须在正文中明确。
- 角度、角速度、速度和加速度分别采用 rad、rad/s、m/s 和 m/s²；工程量级可同时给出 g 或 °/s，但进入算法前统一转换为 SI 单位。
- 公式由 MathJax 渲染。若页面直接显示 `\dot`、`\mathbf` 或孤立的 `\]`，应先检查数学定界符是否缺失，再检查 MathJax CDN 是否加载成功。

当前九章正文已检查行内公式、独立公式和代码围栏的配对关系；第9章综合作业中的三自由度模型、初始状态、时间区间与目标机动公式也已统一为标准 MathJax 语法。

## 本地预览与代码示例

网站为静态文件，可在仓库根目录运行：

```sh
python -m http.server 8000 --directory docs
```

然后打开 `http://localhost:8000`。不要直接双击 `docs/index.html`，否则浏览器可能因本地文件访问限制而无法读取章节 Markdown。单文件 C 示例通常可用 `cc -std=c99 -Wall -Wextra -pedantic example.c -lm` 编译。部分平台的数学库链接选项不同；阅读各示例中的编译说明。网页公式依赖 MathJax CDN，首次预览需要能够访问对应 CDN。

## 使用范围

本手册用于导弹制导、弹体动力学与控制理论教学。简化模型和代码示例不代表任何具体型号能力，也不是可直接部署的软件；工程系统还必须依据弹体构型、导引头/惯导/数据链接口、执行机构、气动数据库和试验规范完成逐级验证。
