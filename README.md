# 制导原理与飞行控制交互手册

面向航空航天、控制及相关专业学习者的中文学术型在线手册。内容从制导几何与相对运动出发，逐步介绍中制导、状态估计、最优与预测方法、飞行器动力学及工程约束，并在对应章节嵌入交互实验。

**GitHub Pages 在线阅读：** https://paoshou-china.github.io/guidance-handbook/

## 内容结构

| 部分 | 章节 | 主题 |
| --- | --- | --- |
| 基础与几何 | 1–3 | 制导系统、坐标系、相对运动 |
| 经典方法 | 4–7 | 追踪、比例导引及三维扩展 |
| 中制导 | 8–13 | 信息结构、预测、航迹跟踪、最优方法、交接与综合案例 |
| 动力学与约束 | 14–16 | 加速度到飞行控制指令、气动、执行器约束 |
| 估计与现代方法 | 17–22 | 状态估计、鲁棒方法、最优/MPC、多飞行器与学习制导 |

每章的实验与本章内容配套，提供参数调整、图形观察或动态响应。实验卡片会注明使用的模型、单位、假设和未覆盖范围；简化教学模型不代表具体飞行器性能。

## 第14章新增：BTT / STT 控制分配

第14章说明期望法向加速度如何映射为飞行控制指令：

- **BTT（倾侧转弯）**：在小侧滑、升力主导近似下，通过倾斜升力矢量分配横向与竖向法向力，得到倾侧角与所需升力，再依据升力模型反解攻角。
- **STT（侧滑转弯）**：通过侧滑产生侧向气动力。由于结果取决于具体气动构型，章节使用侧力系数模型说明局部反解条件，不假设存在通用的倾侧角公式。
- **查表与反馈**：气动数据反解作为前馈映射；PID 属于闭环跟踪与模型误差补偿，不能代替可达性判断或多舵面控制分配。
- **交互实验**：可切换 BTT/STT，调整指令幅值、方向、速度及反馈增益，观察攻角/倾侧角或攻角/侧滑角、实际法向加速度、误差与角度限幅。

该实验采用固定局部气动斜率和一阶响应的教学模型，**不是真实气动数据库插值，也没有实现完整 PID**。它用于展示分配几何及速度、指令大小、角度约束对跟踪的影响；页面正文说明了更一般的受限气动反解和 PID 结构。

## 使用与本地预览

本项目为静态网站，无需后端服务。GitHub 仓库 `docs/` 目录就是 GitHub Pages 发布源，也可在仓库根目录运行 `python -m http.server 8000 --directory docs`，再访问 `http://localhost:8000`。网页公式排版依赖 MathJax CDN。

## 目录

- `content/`：手册章节 Markdown 源文件。
- `docs/`：GitHub Pages 发布目录，包含主页、章节内容、交互实验脚本与样式。
- `site/`：可运行网站源副本。
- `dist/`：Sites 构建目录，包含相同的网站文件。
- `AUDIT-*.md`、`THEORY-*.md`：实验、渲染与理论审阅记录。

## 版权与使用范围

本项目用于一般制导、飞行动力学与控制理论教学。公式和数值实验应结合其假设阅读；示例模型不构成实际飞行器设计、性能保证或操作指令。
