## 第14章：BTT / STT 控制分配

第14章补充了从法向加速度指令到控制量的推导与实验：

- **BTT（倾侧转弯）**：升力主导、小侧滑近似下，通过倾斜升力矢量分配横向与竖向法向力，求所需倾侧角和升力，再由升力模型反解攻角。
- **STT（侧滑转弯）**：以侧滑诱导的侧向气动力产生横向加速度。一般不存在与构型无关的通用反正切解，需基于侧力/升力气动模型反求攻角、侧滑角及相关舵偏。
- **查表与 PID**：气动模型反解提供前馈；PID 用于闭环角度/姿态跟踪和模型误差补偿，不能替代可达性检查或多舵面分配。
- **交互实验**：切换 BTT/STT，调整指令幅值、方向、速度和反馈增益，观察攻角/倾侧角或攻角/侧滑角、实际加速度、跟踪误差及角度限幅。

实验使用固定局部气动斜率、前馈逆映射、比例误差修正和一阶响应。它**不是**真实气动数据库插值或完整 PID 飞控模型；正文给出了更一般的受限查表反解和 PID 结构，二者范围有明确区分。
