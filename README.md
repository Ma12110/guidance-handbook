> 当前版本：完整目录与交互设计大纲。章节正文、代码及网页交互尚待逐章实现；以下模块均为计划内容。

## 阅读主线

几何关系 → 经典制导 → 三维描述 → 中制导与阶段交接 → 动力学约束 → 状态估计 → 最优与学习方法。

## 统一章节结构

每章包含：直观问题与图解、坐标与模型、公式推导、假设与局限、示例代码、交互实验及参考文献。图示标明坐标、单位和矢量方向；交互支持重置、暂停、参数说明和数据导出。公式需区分精确关系与近似关系。
