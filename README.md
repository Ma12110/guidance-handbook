# 制导原理与飞行控制交互手册

面向航空航天、控制及相关专业学习者的中文工程化在线手册。全书压缩为 9 章，覆盖任务流程、三维相对运动、经典制导、中制导与交接、飞行动力学与 BTT/STT、指令整形、状态估计、最优/MPC、多主体与学习方法。

**GitHub Pages：** https://paoshou-china.github.io/guidance-handbook/

## 章节结构

1. 制导系统与任务流程
2. 坐标系与三维相对运动
3. 经典制导律
4. 中制导、预测与全程交接
5. 飞行动力学与 BTT/STT 控制分配
6. 指令整形与执行机构约束
7. 状态估计与鲁棒控制
8. 最优制导与模型预测控制
9. 多主体、学习方法与工程实现

## 每章的工程化内容

每章均按“原理推导—工程接口—C 语言示例—常见错误与排查—交互实验”组织。C 代码采用 C99 风格，注释解释关键变量、边界判断、单位和失败分支；每段代码说明适用范围，不把教学示例误作飞行器软件。常见问题按“现象、可能原因、检查步骤、修正方向”说明。

重点工程主题包括：角度统一用弧度进行内部计算、SI 单位、坐标系和符号约定、指令幅值与速率限制、BTT 倾侧角和攻角指令整形、抖振诊断、气动数据表插值及表外处理、数据有效性检查、故障码与降级策略。BTT/STT 章节分别讲清楚气动反解、前馈和闭环反馈的职责与边界。

## 本地预览与代码示例

网站为静态文件，可在仓库根目录运行：

```sh
python -m http.server 8000 --directory docs
```

然后打开 `http://localhost:8000`。单文件 C 示例通常可用 `cc -std=c99 -Wall -Wextra -pedantic example.c -lm` 编译。部分平台的数学库链接选项不同；阅读各示例中的编译说明。网页公式依赖 MathJax CDN。

## 目录

- `docs/`：GitHub Pages 发布源，含 9 章正文、交互实验和页面资源。
- `docs/content/chapter-01.md` 至 `chapter-09.md`：新版九章正文。
- `docs/content/engineering-standard.md`：全书代码与工程审查规范。
- `docs/content/chapters-*.md`：原始章节材料归档，供追溯旧版细分内容。
- `site/`：网站发布文件的镜像副本。

## 使用范围

本手册用于通用制导、飞行动力学与控制理论学习。简化模型和代码示例不代表具体飞行器能力或可直接部署的飞控软件；实际系统还需依据具体构型、传感器、执行机构、气动数据及安全要求进行设计和验证。
