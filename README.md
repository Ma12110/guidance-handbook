# 导弹制导、导航与控制交互手册

面向航空航天、控制及相关专业学习者的中文在线手册。全书以导弹与动能拦截器为统一对象，从弹目相对运动出发，逐步连接制导律、状态估计、弹体动力学、执行机构约束和硬实时 C 实现。

**在线阅读：**<https://paoshou-china.github.io/guidance-handbook/>

## 章节

1. 导弹 GNC 系统与任务流程
2. 坐标系与三维相对运动
3. 经典制导律
4. 中制导、预测与全程交接
5. 弹体动力学与 BTT/STT 控制分配
6. 指令整形与执行机构约束
7. 状态估计与鲁棒控制
8. APN、ZEM、落角约束、TZC 与 MPC
9. 弹载 C 软件与硬实时实现

## 适合谁

- **理解制导概况：**具备高中数学和基础力学即可开始。
- **独立完成仿真：**建议掌握向量与矩阵、常微分方程、反馈控制、协方差及 C99。

每章包含物理解释、公式推导、适用条件、C 示例、练习答案和交互实验。全书另设一个逐章核对案例与一个独立综合作业，两者参数和用途不混用。

## 统一约定

- 内部计算采用 SI 单位和弧度。
- 相对位置定义为 `目标 − 导弹`。
- 坐标变换统一记作 $C_A^B$：$\mathbf v^B=C_A^B\mathbf v^A$。
- $\int u^2dt$ 表示控制努力二次指标，不直接等同于真实能耗。
- 幅值限制、舵偏速率、姿态参考变化率和加速度变化率分别建模。

```sh
python -m http.server 8000 --directory docs
```

打开 <http://localhost:8000>。C99 示例可按章节给出的命令编译。

## 仓库结构

- `docs/`：GitHub Pages 发布内容
- `docs/content/`：九章正文与工程规范
- `docs/labs-*.js`：交互实验
- `site/`：发布资源镜像
- `scripts/validate_content.py`：内容检查脚本
- `VALIDATION.md`：公式审校与发布验收记录

运行检查：

```sh
python scripts/validate_content.py
```

## 使用范围

本项目用于教学与算法复现。简化模型和示例代码不对应具体型号，也不能未经模型核验、半实物仿真和安全审查直接用于工程系统。
